Scientific disclosure. The model learns simulator-generated shortwave absorption labels—not sensor-measured temperatures. Full physics is a reference computation, not observed ground truth. The reflective-roof scenario uses assumed albedos; the roof rankings indicate modeled reduction in absorbed solar radiation rather than validated cooling or cost effectiveness. Only the original full-physics run generated the reported modeled roof temperature changes. The displayed model benchmark uses a previously inspected spatial-and-date-block test from June 23, 2025. The additional interactive map patches on that same date do not constitute new evaluation data. Field accuracy and full physical generalization are unproven. Historical weather and roof-material assumptions introduce additional uncertainty. All visualizations and data work offline.
